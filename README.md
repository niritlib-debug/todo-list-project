# todo-list-project

## About the Project
This is a simple To-Do List application that allows users to manage their daily tasks.

## Features
- Add new tasks.
- Display tasks in a list.
- Mark tasks as completed using a checkbox.
- Completed tasks appear with a line through the text.

## Technologies
- HTML
- CSS
- JavaScript
- Git and GitHub

## Development Process
The project was developed using GitHub Branches:

- `main` – The main branch containing the final project.
- `feature/add-tasks` – Added the functionality to create new tasks.
- `feature/complete-tasks` – Added the functionality to mark tasks as completed.

Both feature branches were merged into the main branch using Pull Requests.
